## 2024-05-24 - Accessibility of Range Inputs in Scientific UI
**Learning:** For scientific applications with dynamic parameter controls, adding `aria-valuenow`, `aria-valuemin`, and `aria-valuemax` alongside a properly linked `<label>` ensures screen readers can accurately communicate the current value to users. `aria-hidden=\"true\"` on the visual numeric display avoids redundant readout.
**Action:** Always map range input states to ARIA attributes and hide duplicate visual representations from screen readers to prevent cluttered feedback.
## 2024-03-27 - Parameter Reset Button Accessibility
**Learning:** Adding a reset button to a complex parameters UI requires more than just functionality. It needs `aria-label` for screen readers, `title` for visual tooltips on icon-only buttons, `aria-hidden=\"true\"` on the icon itself, and robust `focus-visible` styling to ensure clear keyboard navigation.
**Action:** Always include this a11y triad (aria-label, title, focus-visible) on icon-only reset or utility buttons in control panels.
## 2026-10-08 - Honest labeling of physics tiers in visualization panels
**Learning:** This repo visualizes a research program where claims carry different epistemic weight: the a0 theorem is proven, the BST kernel is phenomenology, the Y-junction is provisional, and several once-visualized ideas (trefoil hadrons, GW echoes, 1/49) are killed. A panel that presents phenomenology with the same visual authority as a theorem misleads the viewer exactly the way the stale README misled readers before the Oct 5 audit.
**Action:** Every visualization info panel MUST state the tier of what it shows, e.g. "a0 = sqrt(E*G_N) [THEOREM]", "BST kernel [PHENOMENOLOGY -- microscopic derivation open]", "Y-junction [PROVISIONAL]". Tiers come from `.jules/physics.md`; never invent, upgrade, or soften one.
## 2026-10-08 - Superseded-banner rule for killed physics
**Learning:** Killed physics (GW echoes, trefoil hadrons, 1/49 loop factor, thermal-fiber cosmology, dark energy from this action) must never appear as live content. Silent removal is also wrong -- dead ideas resurrect when the kill is not visible.
**Action:** NEVER render killed physics as a live tab or default view. If shown for historical comparison, wrap it in a full-panel "SUPERSEDED -- see kill ledger" banner with strikethrough styling on the title, and cite the falsifying evidence. Default tabs show current physics only.
