## 2026-03-24 - Unbounded Timeout Callbacks in React Components | **Learning:** Unbounded asynchronous operations (like `setTimeout` or `fetch`) can trigger state updates on unmounted components, causing memory leaks and React warnings. | **Action:** Always clear intervals, timeouts, and asynchronous subscriptions in the `useEffect` cleanup function to ensure deterministic garbage collection.
## 2025-02-23 - Math.sqrt O(N) Loop Optimization in useFrame | **Learning:** Calling Math.sqrt repeatedly inside a React Three Fiber useFrame loop for thousands of particles creates a severe synchronous bottleneck on the main thread, dropping frame rates. | **Action:** Precompute expensive math operations (like inverse square roots) during initialization (useMemo) and hoist loop-invariant constant calculations out of the O(N) hot path.
